# Inicialización del Proyecto

Este archivo es el punto de entrada para nuevos proyectos que utilizan el AI Development Framework.

## Instrucciones de Configuración

Al iniciar un nuevo proyecto con este archivo:

### Si el directorio `docs/` NO existe (proyecto nuevo):
1. Copiar el directorio `G:\Mi unidad\Sistemas\AI-Development-Framework\templates\ProjectTemplate\docs` y su contenido al proyecto
2. Leer la documentación del framework en `G:\Mi unidad\Sistemas\AI-Development-Framework\docs`
3. Aplicar las reglas del framework definidas allí
4. Preguntar al usuario por su idea de proyecto
5. Hacer preguntas dirigidas para aterrizar la idea y eliminar ambigüedades
6. Documentar la idea clara en `docs/Project.md`
7. Comenzar en la fase de Idea

### Si el directorio `docs/` YA existe (proyecto en progreso):
1. Leer la documentación del framework en `G:\Mi unidad\Sistemas\AI-Development-Framework\docs`
2. Aplicar las reglas del framework definidas allí
3. Leer `docs/Project.md` para determinar la fase actual y estado
4. Continuar trabajando desde la fase actual del proyecto
